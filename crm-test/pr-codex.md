# 林业无人机业务 CRM 系统 — 产品需求文档（Codex 开发版）

> **版本**：V1.2（基于 V1.1 原型迭代 + 开发过程需求变更）  
> **日期**：2026-07-29  
> **定位**：单人使用的轻量级私有 CRM 系统，服务于林业无人机业务的线索获取、商机跟进与客户管理  
> **技术栈**：Python Flask + SQLite + 原生 HTML/JS（SPA 模式）

---

## 一、系统概述

### 1.1 项目背景
面向林业无人机行业（病虫害监测、林区巡检、航拍核查等业务），构建一套个人使用的 CRM 系统，实现从招标线索自动爬取、商机转化、客户/联系人管理、活动记录到看板跟踪的全流程管理。

### 1.2 核心约束
| 约束项 | 说明 |
|--------|------|
| 部署方式 | 私有服务器本地运行 |
| 数据库 | SQLite（单文件，无需额外服务） |
| 用户 | 单用户，无需权限管理 |
| 后端 | Python Flask，最轻量化实现 |
| 前端 | SPA 模式，原生 HTML/CSS/JS |
| AI 集成 | 支持自定义 API Key/Endpoint（OpenAI 兼容协议） |
| 爬虫 | 每日自动爬取指定网站，支持手工注册登录后爬取 |

## 二、原始需求（V1.1 PRD 要点）

### 2.1 功能模块
1. **线索管理**：招标信息的采集、匹配度评估、转化/废弃
2. **商机管理**：阶段推进、金额跟踪、关联线索
3. **客户管理**：客户档案、类型/等级/区域分类
4. **联系人管理**：联系人档案、关联客户
5. **活动记录**：跟进活动记录、下次跟进计划
6. **跟进提醒**：基于活动记录的预计联系日提醒
7. **看板管理**：任务卡片、截止日期、导入商机
8. **系统设置**：AI 配置、爬虫配置、技能管理、选项配置

### 2.2 业务关键词（用于线索匹配）
- 高匹配：无人机飞行检查、无人机林区巡检、航拍核查、林区审计、AI病虫害算法识别、无人机巡检
- 低匹配：林木砍伐、清运、消杀施工
- 全量：松材线虫病防治、林业病虫害监测、无人机巡检、无人机飞行检查、林业航拍核查、林区审计巡检、无人机、林业、病虫害、巡检、航拍、林区、森林、防治、监测

### 2.3 数据模型
- **Lead（线索）**：招标编号、标题、预算、截止日期、属地、采购单位、服务内容、匹配关键词、匹配度、来源平台/URL、状态
- **Opportunity（商机）**：关联线索、客户、联系人、标题、金额、当前阶段
- **OpportunityStage（商机阶段）**：阶段名称、排序
- **StageRecord（阶段记录）**：商机阶段推进记录、内容、截止日期、状态
- **Customer（客户）**：名称、简称、类型、等级、属地、地址、官网、注册资本、从业年限、社保人数、经营范围、知识产权、部门、来源、备注
- **Contact（联系人）**：姓名、简称、职位、电话、邮箱、微信、分管业务、重要性、所属客户
- **Activity（活动记录）**：标题、关联客户/联系人/商机/线索、方式、内容、活动时间、下次跟进时间/内容
- **FollowUp（跟进提醒）**：关联联系人/客户/商机、计划日期、内容、AI 建议内容、实际日期/内容、来源活动
- **KanbanBoard/Column/Card（看板）**：看板、列、卡片（含标签颜色、截止日期、来源类型）
- **SystemConfig（系统配置）**：键值对配置存储
- **Skill（技能）**：技能名称、描述、图标、内置/自定义、启用状态、配置 JSON

## 三、开发过程需求变更（用户确认调整）

### 3.1 架构决策
| 原始设计 | 变更后 | 原因 |
|----------|--------|------|
| 多页面独立 HTML | SPA 单页应用 | 共享数据更方便，后期维护简单 |
| 看板含评论、成员、附件、更新状态 | 仅保留标签和截止日期 | 单人使用无需协作功能 |
| 线索转化后删除原线索 | 保留原线索，可多次转化 | 线索价值可复用 |
| 指定负责人 | 不需要 | 单人使用 |

### 3.2 新增需求
1. **AI 配置验证**：模型配置增加连接测试功能，防止输错 API Key/Endpoint 导致后续无法使用
2. **爬虫真实采集**：爬取按钮需真实爬取指定网站数据，而非仅模拟数据
3. **转商机功能**：线索管理中的"转商机"按钮需真正执行转化逻辑
4. **活动记录关联**：活动记录除选客户外，还需支持选商机和线索
5. **联系人级联筛选**：选客户后，联系人下拉仅展示该客户的联系人
6. **下拉搜索**：所有下拉选择框（客户、联系人、商机等）支持搜索过滤，避免数据量大时无法选择
7. **跟进提醒内容来源**：跟进提醒自动从上次活动中获取预计联系日期和内容，并在提醒中展示完整来源活动信息
8. **客户类型/等级/区域下拉选择**：新增客户时，类型、等级、区域为下拉选择（可配置选项），非直接填写
9. **技能管理**：不仅列出技能，支持上传、启用/禁用、删除自定义技能
10. **数据采集站点配置**：系统设置中可配置爬取目标站点（URL、启用状态、关键词），爬虫按配置真实爬取

### 3.3 已修复问题
| 问题 | 修复方案 |
|------|----------|
| 左侧菜单点击后右侧空白 | SPA 路由修复，showPage 正确切换内容 |
| 排版样式错乱 | CSS 修复，sidebar fixed + main margin-left |
| 审核按钮不可点击 | 移除审核流程，单人使用无需审核 |
| 联系人未按客户筛选 | API 增加 customer_id 参数过滤 |
| 转商机未实现 | 后端 API + 前端 convertLead 完整实现 |
| 爬取仅返回模拟数据 | crawler.py 实现真实 HTTP 爬取中国政府采购网 |
| 下拉无搜索 | 前端所有下拉增加搜索输入框 |

## 五、功能模块详细说明

### 5.1 今日工作台（Dashboard）
- 统计卡片：活跃线索数、商机总数、今日待联络数、紧急线索数
- 紧急线索列表（3 天内截止）：标题、匹配度、关键词、截止日期、关联客户，支持一键转商机
- 商机进展列表：标题、阶段、金额、客户
- 今日待联络列表
- 看板截止提醒

### 5.2 线索管理
- 列表展示：标题、匹配度、关键词、预算、截止日期、状态
- 筛选：匹配度、状态、搜索
- 操作：新增线索、手动爬取、转商机、废弃、查看详情
- 匹配度自动计算：基于关键词匹配（高/中/低）
- 爬取：真实爬取中国政府采购网，按关键词搜索，提取标题/URL/预算/区域/截止日期

### 5.3 商机管理
- 列表展示：标题、客户、当前阶段、金额
- 筛选：阶段筛选
- 阶段管理：添加/删除商机阶段（初步接触→需求调研→方案报价→方案评审→签约谈判→合同签约→项目交付→售后服务）
- 详情页：基本信息、添加阶段记录、阶段时间线
- 阶段记录可添加到看板

### 5.4 客户管理
- 列表：名称、类型、等级、属地、联系人数量
- 新增：名称、简称、类型（下拉）、等级（下拉）、属地（下拉）、地址、官网等
- 详情：基本信息、联系人列表、官方新闻
- AI 采集按钮（需配置 API Key）

### 5.5 联系人管理
- 列表：姓名、职位、所属客户、电话、微信、重要性
- 新增/编辑：姓名、职位、电话、邮箱、微信、重要性、所属客户（下拉筛选）
- 详情：基本信息 + 客户新闻动态

### 5.6 活动记录
- 列表：时间、联系人、客户、方式、内容、下次跟进
- 新增：关联客户（下拉搜索）、联系人（按客户筛选）、商机/线索（下拉搜索）、方式、内容、活动时间、下次跟进时间/内容
- 创建时自动生成跟进提醒（FollowUp）

### 5.7 跟进提醒
- 列表：计划日期、关联客户、关联商机、联系人、内容、AI 建议、来源活动信息
- 自动从活动记录生成
- 支持标记实际跟进日期/内容

### 5.8 看板管理
- 看板 CRUD
- 列：待处理/进行中/已完成（默认）
- 卡片：标题、描述、标签颜色、截止日期
- 导入商机到看板

### 5.9 系统设置
- AI 配置：API Key、Endpoint、模型名称、连接测试按钮
- 爬虫配置：目标站点（名称、URL、启用状态、关键词）、爬取时间、启用开关
- 业务关键词配置
- 技能管理：列表、创建、编辑、启用/禁用、删除、执行
- 选项配置：客户类型、等级、区域（JSON 存储）
