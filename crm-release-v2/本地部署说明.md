# 林业无人机 CRM 本地部署说明

## 版本说明

本部署包基于最新工程化版本（V1.1+）：

- **多用户登录鉴权**：所有接口受 Flask-Login 保护，未登录无法访问数据
- **数据库迁移**：采用 Alembic 管理 schema，升级不断数据
- **前端去 CDN**：React 前端已预构建打包，完全离线可用，无需 Node.js

## 环境要求

- Python 3.10 或更高（仅此一项，无需 Node.js / 数据库）
- 约 200MB 磁盘空间
- 操作系统：Windows / macOS / Linux 均可

## 一键启动

### Windows

双击 `start.bat`

### macOS / Linux

```bash
chmod +x start.sh   # 仅首次需要
./start.sh
```

首次运行会自动创建虚拟环境并安装依赖（约 1-2 分钟），之后启动很快。

启动后浏览器访问：**http://localhost:5001**

## 登录账号

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin123 | 管理员 |

> 首次登录后请立即在「系统设置 → 修改密码」中更改默认密码。
> 也可以在启动前设置环境变量 `CRM_ADMIN_PASSWORD` 自定义初始密码。

## 数据与文件说明

| 路径 | 用途 |
|------|------|
| `instance/crm.db` | SQLite 数据库（所有业务数据，删除即重置系统） |
| `instance/secret_key` | 会话密钥（保证重启后不掉登录） |
| `.venv/` | Python 虚拟环境（删除后下次启动自动重建） |

**数据备份**：只需复制 `instance/crm.db` 文件。
**恢复出厂**：停止服务后删除 `instance/` 目录，重启即重新初始化演示数据。

## 修改端口

默认端口 5001，如被占用：

- Windows：`set CRM_PORT=5002` 后再运行 `start.bat`
- macOS/Linux：`CRM_PORT=5002 ./start.sh`

## 常见问题

**Q：双击 start.bat 闪退？**
用记事本打开 start.bat，在最后一行 `pause` 前查看报错信息；最常见原因是 Python 未加入 PATH，重装 Python 时勾选 "Add Python to PATH"。

**Q：忘记 admin 密码？**
停止服务，删除 `instance/crm.db`（会清空数据），重启后自动重建 admin/admin123。若只想重置密码不想丢数据，可联系管理员在数据库层面处理。

**Q：端口被占用？**
用上面的「修改端口」方法换一个端口。

**Q：升级新版本？**
用新版部署包覆盖本目录（保留 `instance/` 文件夹即可保留全部数据），重启后 Alembic 自动完成数据库迁移。
