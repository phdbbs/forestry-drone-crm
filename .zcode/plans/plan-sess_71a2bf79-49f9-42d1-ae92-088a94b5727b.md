# CRM 前端重构：Vue 3 + Element Plus

## 目标
将 `app/static/index.html`（1849行 vanilla JS 原型）重构为主流前端框架，后端 API 与业务逻辑 100% 不动，界面按标准管理后台规范重做。

## 技术栈（已确认）
Vue 3 + Vite + **Element Plus** + Pinia + Vue Router + **ECharts**（替换 Chart.js），本地打包不再走 CDN。

## 目录结构
```
frontend/                 # 新前端源码
  vite.config.js          # dev 代理 /api→5001；build 输出到 ../app/static/dist
  src/
    api/index.js          # fetch 封装（沿用 {error} 错误约定）+ 各模块 API
    stores/               # Pinia：采集轮询状态、选项字典(options)、系统配置
    router/index.js       # 10 个页面路由
    styles/theme.js       # 绿色林业主题（覆盖 Element Plus CSS 变量）
    components/
      PageTable.vue       # ★通用表格：el-table(可排序/拖列宽/fixed操作列) + el-pagination(默认10条/页,可选10/20/50/100) + 列宽变化自动存 localStorage(crm_v2_widths_*)
      FilterBar.vue       # ★通用搜索栏：输入框回车自动提交、下拉即选即搜、搜索/重置按钮
      DetailGrid.vue      # 详情弹窗字段网格
      StatCard.vue        # 统计图标卡（右侧图标块展示）
    views/                # 10 个页面（业务逻辑照旧，UI 组件化）
      Leads / Opportunities / Contacts / Customers / ContactLog /
      Followups / Dashboard / Kanban / Reports / Settings
```

## 标准功能落实（每个列表页统一）
| 要求 | 实现 |
|------|------|
| 左侧导航自动隐藏 | el-menu 折叠按钮（210px↔64px 图标态）+ 窗口变窄自动收起 + 移动端抽屉 |
| 10条翻页 | el-pagination 默认 pageSize=10，前端分页（数据量几百条，后端不动） |
| 搜索回车提交 | FilterBar 内 el-input `@keyup.enter` 统一触发 |
| 字段点击排序 | el-table-column `sortable`，日期/金额用自定义 sort-method 保证数字序 |
| 列宽调整并保存 | el-table `header-dragend` 事件 → localStorage 按页面自动保存/恢复 |
| 排版规范 | 统一 24px 页边距、el-card 区块、状态/类别语义化 el-tag、斑马纹+hover、操作列 fixed=right、金额右对齐、v-loading、el-empty 空状态、ElMessage/ElMessageBox 替代原生 confirm/prompt/alert |

## 各页面迁移要点（业务流程一字不改）
- **线索**：el-tabs 四个状态页签（带计数）、转化弹窗（中标/非中标两套表单）、详情弹窗、采集按钮+轮询进度条、CSV 导出
- **商机**：阶段 pipeline 条、列表/看板视图切换、行展开详情（联络+阶段 el-timeline 时间轴）
- **客户**：详情弹窗 4 个 tab（联系人/商机/联络记录/动态信息）、采集新闻
- **联系人**：详情+动态采集
- **日常联络**：左表格右统计卡，客户→联系人级联下拉（el-select filterable）
- **联络计划**：执行联络弹窗（自动生成 Activity+下一条计划）、历史记录时间轴
- **看板**：保留 HTML5 拖拽（或换 vuedraggable），弹窗替代 prompt() 命名
- **报表**：ECharts 重画 4 图（月度趋势/漏斗/赢单环图/阶段分布），统一按主题色
- **设置**：4 个配置卡片原样迁移（AI 配置/采集配置/技能/新闻采集+日志）
- **工作台**：统计卡+紧急事项+AI 任务+AI 建议+今日计划+最新商机

## 后端改动（仅 1 处）
`app/__init__.py`：`/` 与 SPA fallback 优先指向 `app/static/dist/index.html`（构建产物），旧版 index.html 保留作回退。其余 API 零改动。

## 实施步骤
1. 脚手架：初始化 frontend/（Vite+Vue3+Element Plus+Pinia+Router+ECharts），绿色主题定制
2. 布局骨架：可折叠侧边栏 + App 布局 + API 封装 + 通用组件（PageTable/FilterBar/DetailGrid）
3. 逐页迁移：线索（最复杂，先做）→ 客户 → 联系人 → 商机 → 日常联络 → 联络计划 → 工作台 → 看板 → 报表 → 设置
4. Flask serve dist + 构建
5. 浏览器逐页验证：分页/回车搜索/排序/列宽保存恢复/弹窗表单/采集轮询/导出/看板拖拽/AI 弹窗
6. 提交并推送 cnb + GitHub + Gitee

## 验收标准
- 10 个页面功能与现在完全等价，无业务回归
- 列宽拖动后刷新页面仍保持；翻页默认 10 条；搜索框回车即查；表头点击排序
- 侧边栏可折叠、窗口缩放自动收起
- `npm run build` 后 Flask 单端口 5001 正常访问
