# 林业无人机 CRM — 本地部署说明

## 环境要求

- Python **3.10 及以上**（https://www.python.org/downloads/）
  - Windows 安装时勾选 **Add Python to PATH**
- 磁盘空间约 200MB（含依赖）
- 无需数据库软件：内置 SQLite，数据存于 `instance/crm.db`

## 一键启动

| 系统 | 操作 |
|---|---|
| macOS / Linux | 终端执行 `./start.sh` |
| Windows | 双击 `start.bat` |

首次运行会自动创建虚拟环境并安装依赖（约 1-2 分钟，需联网），
之后每次启动直接运行脚本即可，无需联网。

启动后浏览器访问：**http://localhost:5001**

## 数据与文件说明

| 路径 | 说明 |
|---|---|
| `instance/crm.db` | 业务数据库（首次启动自动初始化并写入演示种子数据） |
| `instance/secret_key` | 会话签名密钥（首次自动生成，重启不变） |
| `.venv/` | Python 虚拟环境（可随时删除，重新运行脚本自动重建） |

- **备份**：复制 `instance/crm.db` 单个文件即可完整备份全部业务数据
- **重置**：停止服务后删除 `instance/` 目录，重启即恢复初始种子数据
- **换端口**：启动前设置环境变量 `CRM_PORT`（默认 5001）

## 常见问题

**Q: pip 安装依赖慢？**
使用国内镜像安装一次：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```
（在项目目录激活虚拟环境后执行，之后启动脚本会跳过安装）

**Q: 提示"未找到 python"？**
- macOS：`brew install python` 或从官网安装
- Windows：重装并勾选 Add Python to PATH

**Q: 局域网其他电脑访问？**
服务已监听 `0.0.0.0`，用本机局域网 IP 替换 localhost 即可
（如 `http://192.168.x.x:5001`），需放行防火墙对应端口。

**Q: 如何停止服务？**
启动窗口按 `Ctrl+C`（或直接关闭窗口）。

## 生产特性

- waitress 多线程生产服务器（非 Flask 开发服务器）
- SQLite WAL 模式：读写并发不锁库
- 崩溃只需重新运行启动脚本，数据不丢失
